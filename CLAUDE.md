# Закадровый перевод видео через Яндекс

Проект пользователя: из локального видео получается копия с русской озвучкой — дорожка «Перевод»,
оригинал второй дорожкой и файл `.srt`. Основная программа — `yandex_video_translate.py`
(SpeechKit + Translate). Запасная бесплатная версия — `video_translate.py` (v1: Google + Edge).

## Общение
- Весь текст — ответы, отчёты, комментарии в коде, документы — на русском.
- Сухо и по существу; таблицы, алгоритмы и чек-листы там, где они снижают ошибки.
- Неясности задавай пакетом в формате: В. — вопрос, П. — варианты с рекомендацией, Р. — риск и его снижение.

## Старт сессии
1. Прочитай `HANDOFF.md`. Готово, когда можешь назвать текущий следующий шаг.
2. Прогони тесты из таблицы ниже. Готово, когда оба зелёные.

| Что | Команда | Зелёный результат |
|---|---|---|
| Тесты Яндекс-версии | `python tests/test_yandex.py` | `ИТОГ: ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ`, 36 проверок |
| Тесты v1 | `python tests/test_v1.py` | то же, 29 проверок; нужны пакеты v1 из `requirements.txt` |
| Статический анализ | `python -m pyflakes yandex_video_translate.py` | без замечаний |

## Платные вызовы — только по команде пользователя
`--check` и прогон видео обращаются к API Яндекса и списывают деньги со счёта пользователя.
Запускай их, только когда пользователь явно попросил. Для проверки кода используй эмуляцию в `tests/`.

## Секреты
Ключ живёт только в переменной окружения `YC_API_KEY`. Работай с ним через окружение: значение не
выводи, не записывай в файлы и не подставляй в команды.

## Правка запросов к API Яндекса
Перед изменением запросов, лимитов, тарифов или голосов прочитай `docs/yandex-api.md`.
Если реальный ответ API расходится с эмуляцией: обнови `docs/yandex-api.md` и эмуляцию в
`tests/test_yandex.py` так, чтобы тест воспроизводил реальный ответ, затем исправь код.

## Изменение готово, когда
1. Оба теста зелёные, pyflakes без замечаний.
2. Сделано ревью по двум осям: соответствие документации Яндекса и стандартам; соответствие задаче пользователя.
3. Проведена ретроспектива (какие ошибки возникли, какие проверки их поймали) и обновлён `HANDOFF.md`.
