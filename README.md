# Закадровый перевод видео через Яндекс

`yandex_video_translate.py` делает из локального видео копию с русской озвучкой:
дорожка «Перевод» (оригинал приглушён), оригинал второй дорожкой и субтитры `.srt`.

## Регистрация (один раз)
1. Войдите в [консоль Yandex Cloud](https://console.yandex.cloud) под Яндекс ID.
2. Раздел «Биллинг» → «Создать» → «Физическое лицо». Карту российского банка привяжите **сразу при
   создании** — иначе не будет стартового гранта (от 4 000 ₽ на 60 дней).
3. Дождитесь активации платёжного аккаунта (для физлиц есть верификация).
4. [AI Studio](https://aistudio.yandex.cloud/platform) → «Создать API-ключ». Скопируйте ключ — он
   показывается один раз.
5. Сохраните ключ в системе. Windows: `setx YC_API_KEY "ключ"` и откройте новое окно терминала;
   macOS/Linux: `export YC_API_KEY="ключ"` в `~/.zshrc` или `~/.bashrc`.

## Установка
Python 3.9+, `pip install -r requirements.txt`, ffmpeg в PATH (Windows: `winget install Gyan.FFmpeg`).

## Запуск
| Команда | Что делает |
|---|---|
| `python yandex_video_translate.py --check` | Проверка доступа ко всем трём сервисам (≈0,32 ₽) |
| `python yandex_video_translate.py "лекция.mp4" --fast` | Быстрый режим: результат обычно за минуты |
| `python yandex_video_translate.py "лекция.mp4"` | Отложенный режим (≈в 4 раза дешевле распознавание): отправит звук и выйдет; ту же команду запустите позже |
| `... --wait` | Отложенный режим, но ждать результата в окне |

Все параметры: `python yandex_video_translate.py -h`. Правка перевода: исправьте `dst` в
`<имя>_work/translation.json` и запустите ту же команду — переозвучатся только изменённые фразы.

В рабочей папке остаются файлы для разбора ошибок: `stt_raw.txt` — ответ распознавания как есть
(при `--asr yandex`, кроме запусков, где распознавание взято из кэша); `tts_fit.json` — отчёт о
фразах, не помещавшихся в тайминг: запрошенный лимит длительности и что вернул синтез
(при `--fit speechkit`, то есть по умолчанию).

Все видео папки (PowerShell): `Get-ChildItem *.mp4 | ForEach-Object { python yandex_video_translate.py $_.FullName }`.
Уже переведённые файлы пропускаются автоматически.

## Стоимость часа видео (оценка)
≈151 ₽ в отложенном режиме, ≈178 ₽ с `--fast`. Точная сумма выводится после каждого запуска.
Тарифы и источники — в `docs/yandex-api.md`.
